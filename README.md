# Fullstack PERN Ecommerce Web Application
This is a fullstack PERN ecommerce web application built using the following tools:

- Postgres database
- ExpressJS
- Sequelize-typescript
- NodeJS
- Bcrypt
- JSON Web Token
- CORS
- NextJS
- Chakra UI
- RTK
- RTK Query
- Stripe

# Getting Started
To get started with this project, follow these steps:

1. Clone the repository to your local machine.
2. Install the required dependencies by running npm install.
3. Set up the Postgres database and update the configuration file with your database credentials.
4. Run the application using npm start.
